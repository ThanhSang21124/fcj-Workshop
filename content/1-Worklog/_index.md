During my internship period, I followed the AWS Cloud Journey learning path to strengthen my knowledge of cloud computing and gain hands-on experience with AWS services. The program was completed over a period of 12 weeks, covering fundamental AWS services, serverless architectures, monitoring solutions, and Generative AI technologies.

Throughout the internship, I completed a series of workshops and practical exercises provided by AWS Cloud Journey. Each week focused on a specific topic, allowing me to progressively build cloud skills and understand how different AWS services work together in real-world scenarios.

The weekly activities are summarized below:

**Week 1:** [Introduction to AWS Cloud and Global Infrastructure](1.1-week1/)

**Week 2:** [AWS Identity and Access Management (IAM)](1.2-week2/)

**Week 3:** [Amazon EC2 and Virtual Server Deployment](1.3-week3/)

**Week 4:** [Amazon S3 and Cloud Storage Management](1.4-week4/)

**Week 5:** [Amazon RDS and DynamoDB Fundamentals](1.5-week5/)

**Week 6:** [AWS Lambda and Serverless Computing](1.6-week6/)

**Week 7:** [Building APIs with Amazon API Gateway](1.7-week7/)

**Week 8:** [User Authentication with Amazon Cognito](1.8-week8/)

**Week 9:** [Event-Driven Architecture using SNS and SQS](1.9-week9/)

**Week 10:** [Monitoring and Logging with Amazon CloudWatch](1.10-week10/)

**Week 11:** [Generative AI Applications with Amazon Bedrock](1.11-week11/)

**Week 12:** [Project Review, Documentation, and Final Report](1.12-week12/)

By completing these activities, I gained practical experience with AWS cloud services, serverless application development, cloud security, monitoring solutions, and Generative AI technologies. This internship provided valuable hands-on knowledge and strengthened my understanding of cloud-native application development on AWS.
