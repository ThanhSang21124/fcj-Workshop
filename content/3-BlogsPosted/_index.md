This section provides an overview of the blog posts published on the **AWS Study Group**. These articles focus on introducing AWS services, newly released features, and practical cloud solutions in the fields of Generative AI, data processing, and cloud operations. The content is based on research, hands-on experience, and real-world implementation on the AWS platform.

### [Blog 1 - Automating Medical Record Digitization with Amazon Bedrock Data Automation and AWS HealthLake](3.1-Blog1/)

This blog introduces a serverless solution for automating the digitization of medical records by combining **Amazon Bedrock Data Automation (BDA)** with **AWS HealthLake**. It explains how to extract structured information from unstructured medical documents, transform the data into the FHIR standard, and store it for efficient healthcare data management and analytics.

### [Blog 2 - Log Analytics with Facets, Correlation, Enrichment, and Automation in Amazon CloudWatch Log Analytics](3.2-Blog2/)

This blog explores the latest capabilities of **Amazon CloudWatch Log Analytics**, including **Facets**, **Lookup Tables**, **Parameterized Queries**, **JOIN**, **Sub-queries**, and **Scheduled Queries**. It demonstrates how these features improve log analysis, event correlation, data enrichment, and automated monitoring for modern cloud environments.

### [Blog 3 - Securing Multi-Tenant RAG Applications with Amazon Bedrock and Verified Permissions](3.3-Blog3/)

This blog presents an approach to securing **Retrieval-Augmented Generation (RAG)** applications using **Amazon Bedrock Knowledge Bases** together with **Amazon Verified Permissions**. It explains how to implement fine-grained authorization with Cedar policies, enforce role-based access control (RBAC), and protect enterprise knowledge while enabling secure multi-user Generative AI applications.
